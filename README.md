# Excel-Data-Cleaning-Project
A practical Excel data cleaning project demonstrating data quality improvement and data preparation skills.

# Project Overview

This project demonstrates a practical data cleaning workflow using Microsoft Excel. The objective is to improve data quality, consistency, and reliability before performing further analysis.

# Objectives
Identified and removed duplicate records
Handled missing and inconsistent values
Standardized text formats and capitalization
Cleaned and validated date fields
Corrected formatting inconsistencies
Identified invalid and inconsistent data entries
Used Excel formulas and data-cleaning techniques to improve data quality
Prepared the final dataset for analysis and reporting

# Tools Used
Microsoft Excel
Excel Formulas
Data Validation
Find & Replace
Text to Columns
Conditional Formatting
